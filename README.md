# Skripsi Konsolidasi: Model Tereduksi Pipa Kalor Natrium untuk ISR

Naskah skripsi lengkap (73 halaman) beserta kode yang menghasilkan setiap angka
di dalamnya.

- **Baca**: `_output/skripsi.pdf`
- **Audit angka & catatan penggabungan**: `CATATAN-KONSOLIDASI.md`
- **Hitung ulang**: `cd src && python run_all.py && python make_tables.py`
- **Render**: `quarto render skripsi.qmd` (butuh XeLaTeX)

Dependensi Python: numpy, pandas, matplotlib.
